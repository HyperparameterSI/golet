## 同步内容

| 范围 | 更新 | 上游提交 |
| --- | --- | --- |
| 原生菜单 | `Element.PopoverMenuButton`：点击或键盘展开主题菜单，支持边缘翻转、子菜单、工具栏和无障碍 | `d7282567` |
| 菜单定位 | 元素部分滚出视口时，右键菜单正确出现在鼠标位置 | `85fd4bba` |
| 输入控件 | SearchField、TokenField、Combobox 的 Placeholder 传递给内部输入框 | `f27a1253` |
| 日历 | 用路径绘制并居中月份切换箭头，支持 RTL | `e5547238` |
| 文本编辑 | Diff 删除条纹跨行连续；macOS 编辑菜单 Paste 能触发窗口 Cmd+V 处理器 | `ac4e0ff0`、`4aca72f1` |
| macOS | 避免在 AppKit 显示事务中执行按钮回调，使文件/保存/消息对话框和 sheet 正常显示；主队列支持嵌套事件循环 | `bca8cf33` |
| Linux | 在绘制中请求 Hide 时延迟隐藏，避免 GTK 绘制仍在使用的 GL 上下文被释放 | `aa753d22` |
| Windows | 调整 D3D11 呈现与窗口尺寸处理，避免拖动调整大小时画面被放大，以及缩小窗口时露出黑色区域 | `c1467c1a`、`23bef6cc` |
| WebView | `PageOptions.PreloadAllFrames` 可将应用预加载脚本注入所有 iframe | `3d9d668c` |
| Terminal | `Options.ScrollMultiplier` 和 `SetScrollMultiplier` 分别控制触控板与鼠标滚轮倍率 | `cbee0b21` |

预加载选项默认关闭。开启后应用的 PreloadScript 可进入不同来源的 iframe，
但 Golet IPC 桥依然只在顶层页面中注入，iframe 不会因此取得 `window.golet`。
该选项属于系统 WebView，不能等同于可选 CEF Browser 的配置。

## Golet 适配与演示

- 保留 backend/frontend 布局、Forma、Chromium、Scene3D、主题和结构化日志。
- Studio 的“弹层与反馈”同步演示 PopoverMenuButton：卡片右侧 More 按钮可展开原生绘制菜单，与右键菜单共享选项。
- 新增的 macOS 对话框回归测试等待实际帧调度器进入暂停状态，不用固定休眠推测窗口是否就绪。
- 这些更新随 Golet 0.1.14 发布。


因此基础原生示例有小幅增长。本次主要修复正确性与交互，不宣称整体运行速度提升。
