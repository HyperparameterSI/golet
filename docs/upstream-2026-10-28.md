这些 WebView API 操作系统 WebView；它们不会自动扩展可选 CEF Browser 的 API。
各平台能力差异保留在公开 Go 注释和文档中，例如 macOS 14 前自定义持久会话的限制。
原生 Video 当前包含 GIF 解码器及可扩展 `VideoDecoder` 接口，不代表内置 MP4/H.264 解码器。

- 不复制 MyGo 的品牌、第三方 showcase 应用、上游 npm 版本号或发布记录。

## 使用示例

原生视频演示：

```sh
go run ./backend/examples/video
# 或 pnpm dev，在 Studio 打开“绘图与图像”
```

原生控件可显式缓存复杂且变化较少的内容，并限制自定义动画帧率：

```go
// Author: HyperparameterSI
ui.Box(c).Size(320, 200).Cache().Children(func() {
    ui.Text(c, "Cached content")
})
ui.Box(c).Size(160, 80).Draw(func(p *ui.Painter, r ui.Rect) {
    p.AnimationFrameRate(30)
    // Use p.Now() to advance the drawing.
})
```

系统代理不修改 `http.DefaultTransport`：

```go
// Author: HyperparameterSI
client := &http.Client{Transport: netproxy.Transport()}
```

自动化的启用与协议见 [automation](plugins/automation.md)。

## 验证和体积

宿主为 macOS arm64 / Apple M5，`CGO_ENABLED=0`。基础应用采用相同 Go 1.27.3、
`-trimpath -tags golet_noinspector -ldflags '-s -w -X github.com/HyperparameterSI/golet/backend.production=1'`，
对比同步前提交 `e5f88d7102db73bc850ad9a1af7ed7870e70b23a`：

| 应用 | 同步前（字节） | 同步后（字节） | 变化 |
| --- | ---: | ---: | ---: |
| counter-native | 9,266,866 | 9,455,634 | +188,768（2.04%） |
| hello | 9,422,738 | 9,644,594 | +221,856（2.35%） |

使用 `-dumpdep` 和 Mach-O 符号对比检查了体积增长。主要新增路径为公共平台窗口
回调/元数据、认证与页面事件、文本断行和软连字符，以及局部重绘/GPU 损伤处理。
在 counter-native 链接结果中未发现 VideoPlayer、GIF 解码、netproxy、automation、
自定义会话存储构造和 NowPlayingModule 的实现；没有为这些未使用的可选功能引入重依赖。
本次更新有基础功能体积成本，并非零增长，也不声称所有场景性能都会提高。

已完成的检查：

- `CGO_ENABLED=0 go test ./...` 全量通过（默认不启动 GUI 测试）。
- macOS/Linux/Windows 构建和 vet、三平台 `golet_noinspector` vet、js/wasm vet 通过。
- Intel macOS、Windows ARM64、Windows/Linux 386 和 FreeBSD 交叉编译通过。
- Bun 226 项测试通过；工作区构建、TypeScript 类型检查、前端格式检查及 Studio 生产构建通过。
- macOS 实机单独通过 `TestSessions`、`TestEphemeralSession`、`TestSessionState`、
  `TestContentWindowRepaintsWhatChanged`、`TestPageContextMenu`、`TestPageContextMenuCancelled`、
  `TestPageThemeColor`、`TestAuthHandler`、`TestWindowFitContent`。
- Windows/Linux 运行时行为仍须在对应系统或 CI 验证；交叉编译不等同于实机验证。

在关闭本次并行构建任务后，以相同工具链顺序执行三次 CPU 渲染基准，取中位数：

| 基准 | 同步前 | 同步后 | 分配次数（前/后） |
| --- | ---: | ---: | ---: |
| FrameHover | 61.106 μs | 66.857 μs | 56 / 56 |
| FrameAnimatedPaths | 415.978 μs | 352.991 μs | 14 / 14 |
| DiffSteady | 551.677 μs | 527.383 μs | 2 / 2 |

命令：`go test ./backend/ui -run '^$' -bench '^(BenchmarkFrameHover|BenchmarkDiffSteady|BenchmarkFrameAnimatedPaths)$' -benchmem -count=3`。
这些是本机微基准，单次样本波动明显：动画路径中位数下降约 15%，悬停则上升约 9%。
因此不能据此宣称整体加速，更不能承诺 10 倍性能提升。
缓存、限帧和多个损伤矩形的收益取决于应用是否有可缓存内容和局部变化；
相关回归测试检查重绘范围、帧请求及渲染一致性，而非依赖墙钟时间判定通过。
